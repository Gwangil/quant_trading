# 01. 전략 설계 — 분할 바스켓 LOC 전략

## 1. 요구사항 정리

| 요구 | 설계 반영 |
|---|---|
| 미국 레버리지 반도체 ETF(SOXL 등) 대상 | 매매 대상 `symbol`, 추세·변동성 판단용 기준지수 `reference`(SOXX) 분리 |
| 하루 한 번, 종가 기반(LOC) 주문 | 매일 종가 후 다음 거래일 **LOC/MOC 주문표**를 만들고, 체결은 다음 종가에서만 판정 |
| 저점·고점 추정이 아니라 **떨어지면 사고 오르면 판다** | 매수 지정가 = 전일종가 × (1 − 하락률) → 하락 마감일에만 체결. 매도 지정가 = 로트 매입가 × (1 + 목표율) → 반등 마감일에만 체결 |
| 하락장에서도 반등 때마다 팔아 자금을 확보 | **로트 단위 익절**: 싸게 산 최근 로트가 반등 시 먼저 목표에 닿아 팔리고, 그 현금이 바스켓으로 돌아와 다음 하락 매수에 재사용 |
| 자산을 바구니로 나눠 안정적으로 회전 | N개 **바스켓**(예산 단위). 각 바스켓은 독립 라운드를 돌며 목표수익 / 손실한도 / 보유기간 만료로 전량 청산 후 재시작 |
| 자산 규모 가변 | 바스켓 예산 = 오픈 시점 총자산 × 비율 → 자산이 늘면 예산도 커짐(복리), 줄면 작아짐 |
| MDD 와 회복탄력성 관리 | 기준지수 200일선 레짐 필터, 약세장 바스켓 수·매수규모 축소/초과분 청산, 바스켓 손절, 포트폴리오 낙폭 브레이크(옵션) |
| 단리 연 20~30% | 리포트에 단리 연환산·CAGR·MDD·회복일수·최장 수중기간을 함께 산출, 파라미터 탐색 시 MDD 제약 하에 단리수익 최대화 |

## 2. 구조

```
총자산 (현금 + 보유주식)
 ├─ 바스켓 1 : 예산 B1 ─ 로트 [매입가, 수량] ... ─ 실현손익
 ├─ 바스켓 2 : 예산 B2 ─ ...
 ├─ ...
 └─ 미배정 현금 (새 바스켓 오픈 대기)
```

### 2.1 바스켓 라이프사이클

1. **오픈**: 활성 바스켓 수 < 허용치(강세 N / 약세 `bear_max_baskets`) 이고, 직전 오픈 후 `min_days_between_opens` 거래일이 지났으면 오픈.
   예산 = min(총자산 × `budget_frac`(기본 1/N), 미배정 현금). 오픈과 동시에 첫 슬라이스 LOC 매수 주문.
2. **라운드 진행** (매일 종가 후 주문 생성):
   - 매수 LOC: 잔여 현금이 있으면 `예산/slices` 만큼, 지정가 = 종가 × (1 − dip).
     `dip = clamp(dip_vol_mult × σ20, min_dip, max_dip)` — 변동성이 커지면 더 깊은 하락에서만 산다.
     첫 슬라이스만 `first_slice_dip_pct`(기본 0 = 보합 이하 마감이면 체결).
   - 매도 LOC: 보유 로트마다 지정가 = 매입가 × (1 + tp), `tp = clamp(lot_tp_vol_mult × σ20, min_tp, max_tp)`.
     `lot_tp_sell_frac` < 1 이면 일부만 익절하고 나머지는 바스켓 청산까지 보유(추세 이익 일부 보존).
3. **청산(전량 MOC)**: 아래 중 하나가 먼저 오면 다음 거래일 종가에 전량 매도 후 바스켓 종료, 현금은 미배정 풀로 복귀.
   - `basket_tp_pct`: 예산 대비 손익 ≥ 목표 (예: +10%)
   - `basket_sl_pct`: 예산 대비 손익 ≤ −한도 (예: −25%) — 3배 ETF 에서는 이게 MDD 를 결정적으로 줄임
   - `max_hold_days` 경과 & 손익 ≥ `soft_exit_pnl_pct`(기본 0): "본전 이상이면 시간 청산"
   - `hard_max_hold_days` 경과: 무조건 청산 (장기 물림 방지, 자금 회전 강제)
   - `regime_bear`: 약세 전환 시 `bear_max_baskets` 초과분을 수익률 낮은 순으로 청산 (`bear_liquidate: true`)

### 2.1.1 invest_strategy v5 에서 가져온 두 규칙 (실데이터 재검증 후 추가)

- **상승일 부분매도** (`exit.upday_sell_frac`): 보유 로트가 있는 바스켓은 매일 "지정가 = 전일종가" 로 보유수량의 일부(예: 20%)를 매도 LOC 로 낸다.
  상승 마감일에만 체결되므로 하락장 반등마다 현금을 회수하는 변동성 수확이 된다. 로트 비례로 수량을 줄이며, 로트 익절 LOC 와 같은 날 둘 다 체결될 수 있다.
- **계좌 서킷브레이커** (`regime.breaker_dd`, `regime.breaker_resume_sma`): 총자산이 고점 대비 `breaker_dd`(예: 15%) 이상 빠지면 다음 거래일 전량 MOC 청산 후 매매 중단.
  매매 대상 종가가 `breaker_resume_sma`(예: 200일) 이동평균 위로 복귀하면 재개하고 고점을 현재 자산으로 리셋한다. 기준지수 레짐 필터와 독립적으로 동작하며, 둘 다 끄거나 켤 수 있다.

### 2.2 레짐(추세) 필터 — MDD 관리의 핵심

- 기준지수 종가 > `ma_window`일 이동평균 → **강세**, 아니면 **약세**.
- 약세장: 동시 바스켓 ≤ `bear_max_baskets`, 슬라이스 크기 × `bear_slice_mult`, (옵션) 신규매수 중단.
- 왜 무레버리지 기준지수로 판단하나: 레버리지 ETF 가격은 변동성 붕괴로 추세가 왜곡되므로, 기초지수의 200일선이 더 안정적이다.
- (옵션) `portfolio_dd_brake`: 전략 자산이 고점 대비 이 비율 이상 빠지면 `portfolio_dd_brake_days` 동안 약세로 강제.

### 2.3 왜 이 구조가 MDD 와 회복탄력성에 유리한가

- **분할 바스켓 + 슬라이스**: 하루 최대 투입은 `활성 바스켓 수 / slices` 만큼으로 제한된다. 급락 첫날에 몰빵되지 않는다.
- **로트 익절**: 하락장에서 산 싼 로트가 반등에서 먼저 팔려 현금이 돌아온다 → 저점 근처에서 매수 여력이 유지된다(회복 국면 참여).
- **시간 청산**: 물린 바스켓이 무한정 자본을 잠그지 못한다. 회복 시 새 예산(현재 자산 기준)으로 재출발한다.
- **약세 레짐 축소**: 2000~2002, 2008, 2022 같은 −70~−90% 레버리지 붕괴 구간에서 노출을 10~20% 이하로 낮춘다. 이 규칙 없이는 3배 ETF 로 어떤 분할매수도 MDD −70% 이상을 피하기 어렵다(백테스트 결과 참조).

## 3. 체결 모델 (백테스트 = 실전 주문 규칙)

| 주문 | 체결 조건 | 체결가 |
|---|---|---|
| BUY LOC (지정가 L) | 종가 ≤ L | 종가 |
| SELL LOC (지정가 L) | 종가 ≥ L | 종가 |
| SELL MOC | 항상 | 종가 |
| SELL LOC 상승일 부분매도 (지정가 = 전일종가) | 종가 ≥ 전일종가 | 종가 |

- 수수료 편도 0.07% (기본), 슬리피지 0 (종가 단일가 체결 가정).
- 미국 시장 LOC 주문은 장 마감 직전까지 접수되므로, **전날 밤(한국 시간) 주문표를 만들어 두고 개장 전에 넣으면** 된다.

## 4. 주요 한계와 유의점

1. **데이터**: 실제 SOXL 은 2010년 상장. 이전 구간은 SOXX 로부터 합성(`backfill`)하거나, 번들 NASDAQ 프록시(1999~2018)로 검증한다. 합성은 보수(0.95%)·조달비용(2%)만 반영하며 실제 ETF 의 추적 오차·배당은 반영하지 않는다.
2. **과최적화**: 파라미터 탐색은 반드시 학습/검증 구간을 나눠 본다(`sweep --split`). 검증 구간 성과가 학습 구간의 절반 이하로 떨어지면 그 조합은 버린다.
3. **연 20~30% 단리 목표**는 강세 구간에서는 달성되지만, 2000~2002 급의 붕괴가 포함된 구간에서는 미달한다. 목표를 "장기 평균"으로 이해하고 MDD 제약을 우선하는 것을 권한다.
4. **세금·환율** 미반영. 해외주식 양도세(22%)와 원/달러는 실질 수익률에 크게 영향을 준다.
