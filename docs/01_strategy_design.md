# 01. 전략 설계 — SOXL 분할 바스켓 LOC

전략 요약과 결과는 docs/00, 검증 기록은 docs/02. 이 문서는 바스켓 전략의 설계 근거와 체결 모델을 적는다.

## 1. 요구사항 → 설계

| 요구 | 설계 반영 |
|---|---|
| 레버리지 반도체 ETF(SOXL) 대상 | 매매 대상 `symbol`, 추세 판단용 기준지수 `reference`(SOXX, 무레버리지) 분리 |
| 하루 한 번 종가 기반(LOC) 주문 | 매일 종가 후 다음 거래일 LOC/MOC 주문표 생성, 체결은 다음 종가에서만 판정 |
| 저점·고점 추정이 아니라 **떨어지면 사고 오르면 판다** | 매수 지정가 = 전일종가 × (1 − 하락률) → 하락 마감일에만 체결. 매도 지정가 = 로트 매입가 × (1 + 목표율) → 반등 마감일에만 체결 |
| 하락장에서도 반등마다 팔아 자금 확보 | 로트 단위 익절 + 상승일 부분매도 10%. 싸게 산 로트가 반등에 먼저 팔리고 현금이 바스켓으로 돌아와 재사용 |
| 자산을 바구니로 나눠 안정적으로 회전 | 바스켓 4개, 각 바스켓은 독립 라운드(목표수익 / 보유기간 만료로 전량 청산 후 재시작) |
| 자산 규모 가변 | 바스켓 예산 = 오픈 시점 총자산 / 4 (복리) |
| MDD·회복탄력성 관리 | SOXX 200일선 레짐(약세장 바스켓 1개, 초과분 청산, 쿨다운), 변동성 타게팅 슬라이스, 손절 없음 |
| 단리 연 20~30% | 단리 연환산은 장기 복리로 과장되므로 CAGR 로 판단. OOS(2018~) CAGR 24%, 전체 17% |

## 2. 구조

```
총자산 (현금 + 보유주식)
 ├─ 바스켓 1 : 예산 B1 ─ 로트 [매입가, 수량, 매입일] ... ─ 실현손익
 ├─ 바스켓 2..4
 └─ 미배정 현금 (새 바스켓 오픈 대기, 80% 단기채 파킹)
```

### 2.1 바스켓 라이프사이클
1. **오픈**: 활성 바스켓 < 허용치(강세 4 / 약세 1), 직전 오픈 후 `min_days_between_opens` 경과, 오픈 후 쿨다운(`cooldown_after_sl_days`) 아님. 예산 = min(총자산/4, 미배정 현금). 오픈과 동시에 첫 슬라이스 LOC 매수(`first_slice_dip_pct`=0 → 보합 이하 마감이면 체결).
2. **라운드 진행** (매일 종가 후):
   - 매수 LOC: 잔여 현금이 있으면 `예산/slices`, 지정가 = 종가 × (1 − clamp(`dip_vol_mult`×σ, `min_dip_pct`, `max_dip_pct`)). σ 가 `target_vol` 을 넘으면 슬라이스 × target_vol/σ. 약세장 × `bear_slice_mult`.
   - 매도 LOC: 로트마다 지정가 = 매입가 × (1 + clamp(`lot_tp_vol_mult`×σ, `min_lot_tp_pct`, `max_lot_tp_pct`)). 같은 지정가 로트는 한 주문.
   - 상승일 부분매도 LOC: 보유수량 × `upday_sell_frac`, 지정가 = 종가(상승 마감 시 체결). 로트 비례 차감.
3. **청산 (MOC)**: `basket_tp_pct` 도달 / `max_hold_days` 경과 & 손익 ≥ `soft_exit_pnl_pct` / `hard_max_hold_days` 경과 / 약세 전환 시 초과분(`regime_bear`) / (공격형) 서킷브레이커. 청산 현금은 미배정 풀로.

### 2.2 레짐 — MDD 관리의 핵심
- 기준지수 종가 > `ma_window`일 이동평균 → 강세. 약세장: 동시 바스켓 ≤ `bear_max_baskets`, 슬라이스 × `bear_slice_mult`, 초과분 청산(`bear_liquidate`), 청산 후 `cooldown_after_sl_days` 신규 금지.
- 무레버리지 기준지수로 판단하는 이유: 레버리지 ETF 가격은 변동성 붕괴로 추세가 왜곡된다.
- 밴드(`ma_band`)는 근사 SOXX 데이터에서만 유리했고 실제 종가에서는 0 이 낫다. 변동성 급등 신호, 판정 주기 변경, 이평 기울기, 이중 이평은 모두 낙폭을 줄이지 못했다(기각, docs/02 §3·docs/07 §4.7).
- (공격형만) 계좌 서킷브레이커 `breaker_dd`: 총자산이 고점 대비 이 비율 이상 빠지면 전량 MOC 청산·중단, 매매 대상 종가가 `breaker_resume_sma` 위로 복귀하면 재개. 균형형·방어형은 너무 자주 발동해 CAGR 만 깎으므로 끔.

### 2.3 왜 이 구조가 낙폭·회복에 유리한가
- 분할 바스켓 + 슬라이스: 하루 최대 투입 ≈ 총자산 × 활성 바스켓/4 / slices.
- 로트 익절 + 상승일 부분매도: 반등마다 현금이 돌아와 저점 근처에서 매수 여력이 유지된다. 부분매도 0 → 10% 가 MDD −45% → −28%.
- 시간 청산: 물린 바스켓이 자본을 무한정 잠그지 못한다.
- 약세 레짐 축소: 2008·2022 급의 붕괴에서 노출을 1/4 이하로.
- 손절은 해롭다: whipsaw 손실을 확정만 시킨다(실데이터 검증). 낙폭 뒤 규모 축소도 회복을 4배 늦춘다. **심리 방어는 사전 노출 제한(투자비중 16%)과 GLD 슬리브로 만든다.**

## 3. 체결 모델 (백테스트 = 실전 주문 규칙)

| 주문 | 체결 조건 | 체결가 |
|---|---|---|
| BUY LOC (지정가 L) | 종가 ≤ L | 종가 |
| SELL LOC (지정가 L) | 종가 ≥ L | 종가 |
| SELL LOC 상승일 부분매도 (L = 전일종가) | 종가 ≥ 전일종가 | 종가 |
| SELL MOC | 항상 | 종가 |

수수료 편도 0.1%, 슬리피지 0(종가 단일가 가정, 실측 후 `costs.slippage_pct`). 미래참조 없음: 당일 종가 정보로 다음 거래일 주문.

## 4. 한계와 유의점
1. **데이터**: 2010-03 이전 SOXL 은 SOXX×3 합성(보수·추적오차 미반영). 주 검증은 `data/cache`(실제 SOXX 종가).
2. **과최적화 방지**: IS ~2017 / OOS 2018~ 분리 + 롤링 워크포워드 5개 창(docs/02 §3.1). 채택 파라미터 이웃에 절벽 없음(docs/02 §4).
3. **횡보 whipsaw** 가 낙폭의 원인이며 규칙으로 못 줄인다. GLD 슬리브(docs/00 전략 B)로 완화.
4. **세금·환율**: 의사결정은 세전 달러. 세후 원화는 `qtrade tax` (docs/02 §7).
5. **경로 의존**: 공격형은 시작일에 따라 MDD −41~−52% 로 달라진다. 균형형·방어형은 안정적.
