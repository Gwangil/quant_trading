## 1. 최종 프로필 3종 (`src/qtrade/profiles.py`)

공통 코어: 바스켓 4개 × 슬라이스 6, 매수 지정가 = 전일종가 × (1 − 0.25σ), 로트 익절 = 매입가 × (1 + 1.0σ, 3~15%),
바스켓 청산 = +20% / 60일(본전 이상) / 120일 강제, **바스켓 손절 없음**, SOXX 200일선 ±2% 레짐(약세장 바스켓 1개·슬라이스 ×0.5·초과분 청산, 청산 후 20일 쿨다운), 변동성 타게팅 슬라이스(σ>4.5%).

| 프로필 | 차이 | 성격 |
|---|---|---|
| **방어형** `soxl_defensive` | 상승일 부분매도 20%, 연 30% 변동성 노출상한 | 낙폭 −26%, 낙폭 20% 초과 체류 3.6% |
| **균형형** `soxl_balanced` (기본) | 상승일 부분매도 10% | 낙폭 −36%, CAGR 15.7% |
| **공격형** `soxl_aggressive` | 슬라이스 4, 계좌 서킷브레이커 −25% | 낙폭 −43%, CAGR 20% |

## 3. 어떤 규칙이 무엇을 바꿨나 (실데이터 탐색 요약)

탐색 순서: 나스닥 프록시 4단계(1,440조합) → 실데이터 재탐색(192) → v5 결합(288+81) → 리스크 레이어(48). 원본 CSV: `reports/sweeps/`.

| 규칙 | 결과 | 채택 |
|---|---|---|
| SOXX 200일선 레짐 (약세장 바스켓 축소·초과분 청산) | 없으면 MDD −70% 이상. 있어도 밴드 없이는 2010~2012 whipsaw 로 3년 연속 손실 | ON, 밴드 ±2%, 약세장 바스켓 1개 |
| 바스켓 손절 −25% | 수익만 깎고 MDD 는 동일 (whipsaw 손실 확정) | 제거 |
| 로트 익절 크기 | 0.5~1.0σ 가 1.5σ 이상보다 MDD −10%p. 작은 익절을 자주 실현하는 변동성 수확이 SOXL 에 맞음 | 1.0σ |
| **상승일 부분매도** (v5) | 0→10%: MDD −52%→−36%, 회복 539→411일, CAGR 22.9→15.7%. 20%: MDD −31%, CAGR 11.9% | 10% (방어형 20%) |
| 계좌 서킷브레이커 −15% (v5) | 복리 예산 구조에서는 너무 자주 발동해 CAGR −5%p. −25% 는 중립 | 공격형만 −25% |
| **변동성 타게팅 노출상한** 연 30% | MDD −34%→−30%, 낙폭>20% 체류 절반, 회복 30% 단축, CAGR −3%p | 방어형 |
| **낙폭 연동 축소** (자산이 빠지면 매수 축소) | **역효과**: 회복 451→2,119일, Ulcer 악화. 저점에서 매수를 줄여 반등을 놓침 | 제거 |
| 폭락일 증액(depth_boost) | 나스닥 프록시에서 MDD 악화 (invest_strategy v4 와 동일 결론) | 0 |

핵심 교훈: 심리 방어는 "빠진 뒤 줄이기"가 아니라 **"평소 노출을 낮게 유지하고(변동성 상한), 반등마다 일부를 실현(상승일 부분매도)"** 로 만든다.

두 접근을 결합한 현재 균형형은 v5 의 "반등마다 일부 실현" 을 받아들이고, 복리 예산·변동성 비례 폭·기준지수 레짐을 유지한 형태다.
같은 단리 기준 비교는 `qtrade backtest -c configs/soxl_balanced_hybrid.yaml` 에 `baskets.budget_mode: fixed` 를 적용해 재현할 수 있다.

## 6. 남은 과제 / 제안

1. **현금 파킹**: 평균 투자비중 12~23% → 대기 현금을 SGOV/BIL 등에 두면 연 3~4%p 가 거의 무위험으로 더해진다 (`cash_yield_annual: 0.04`).
2. **실운용 검증**: 2026-07-24 이후 데이터로 `qtrade backtest -c configs/soxl_balanced.yaml`(yfinance) 재실행, 주문표 vs 실제 체결 오차 기록.
3. **레짐 신호 확장**: SOXX 실현변동성 급등을 약세 신호에 추가(미탐색). 2010~2012 형 횡보장 whipsaw 를 더 줄일 여지.
4. **롤링 워크포워드**: 현재는 IS/OOS 1회 분할. 4~5개 창으로 나눠 파라미터 안정성을 다시 확인할 것.
5. **세금·환율**: 미반영. 부분매도·시간청산이 잦아 양도세(22%) 영향이 크다.
